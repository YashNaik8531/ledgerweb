LedgerWeb is a web-based digital ledger designed for small shopkeepers and local businesses to record and manage customer transactions easily.
Traditional shopkeepers often maintain customer payment records in notebooks. This can make it difficult to search records, maintain separate debt and paid transactions, and keep track of multiple customers.
LedgerWeb provides a simple digital solution where a shopkeeper can create an account, record transactions using voice input, and view their transaction history in an organized dashboard.
The main purpose of LedgerWeb is to make transaction recording:
Simple
Fast
Organized
Digital
Easy to use for shopkeepers
Instead of manually typing every transaction, the shopkeeper can speak the transaction, and the system uses Google Gemini AI to understand the spoken information and extract the required details.
How LedgerWeb Works

The website follows this basic process:

Shopkeeper
     ↓
Create Account / Sign In
     ↓
Dashboard
     ↓
Record Transaction
     ↓
Speak the Transaction
     ↓
Gemini AI analyzes the audio
     ↓
Customer Name + Amount + Transaction Type
     ↓
Shopkeeper reviews the information
     ↓
Confirm & Save
     ↓
MySQL Database
     ↓
Transaction appears in Ledger
